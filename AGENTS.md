# AGENTS.md

Инструкции для AI-агентов (Claude Code и др.), работающих с этим репозиторием. Люди: см. [README.md](README.md).

## Что это

Статический портфолио-сайт (Astro 7 + MDX + чистый CSS), деплой на GitHub Pages. Дизайн — Figma `KkKl7hBIxrS5pe477oRo65` (файл «Portfolio»). Язык интерфейса и текстов — русский.

## Репозиторий и деплой

- GitHub: `XeniaSv/XeniaSv.github.io` (переименован из `portfolio`; `origin` указывает на новый адрес). Локальная папка проекта может называться `portfolio` — это нормально.
- Пользовательский сайт GitHub Pages: `https://xeniasv.github.io/`, корневой путь → `base` не нужен. Публикация — GitHub Actions (`.github/workflows/deploy.yml`) при пуше в `main`; в Settings → Pages источник — **GitHub Actions**.
- Пушить в `main` только по явной просьбе пользователя.

## Команды

Node.js ≥ 22.12 (на Windows после установки может потребоваться перезапуск шелла, чтобы `node` появился в PATH).

| Команда | Назначение |
|---|---|
| `npm run dev` | dev-сервер `http://localhost:4321` (в Claude Code: `preview_start` с конфигурацией `portfolio-dev` из `.claude/launch.json`) |
| `npm run build` | сборка в `dist/` — обязательна перед завершением задачи |
| `npm run check:links` | проверка внутренних ссылок/якорей/ассетов в `dist/` |
| `npm run preview` | просмотр собранного сайта |

Перед сдачей любого изменения: `npm run build && npm run check:links` должны проходить без ошибок.

## Архитектура и соглашения

- **Контент отделён от вёрстки.** Страницы проектов — `src/content/projects/<slug>.mdx` (схема в `src/content.config.ts`). Шаблон один: `src/layouts/ProjectLayout.astro`. Маршрут `/projects/<slug>/` создаёт `src/pages/projects/[slug].astro`. Не копируйте HTML страницы — добавляйте `.mdx`.
- **Главная** собирается из `src/data/home.ts` (секции → карточки; карточки в секции чередуются автоматически). Карточка с `project: '<slug>'` берёт данные и ссылку из frontmatter детальной страницы; без `project` карточка описана в `home.ts` целиком: тексты, `gallery` (папка `src/assets/works/<раздел>/<проект>/`, файлы `1-…`, `2-…` по порядку; первый — превью, все вместе — миниатюры) и `href` на внешний сайт/видео. Таких проектов (реализованные, ведение, концепты) детальных страниц нет — только учебные.
- **Тексты сайта/контакты** — только в `src/config/site.ts` (не хардкодить в компонентах).
- **Ссылки** на страницы и `public/`-файлы — всегда через `url()` из `src/lib/url.ts` (учитывает `base` для проектного сайта). Внутренние ссылки — с завершающим `/`.
- **Картинки** лежат в `src/assets/` и импортируются (так Astro оптимизирует их в webp и подставляет размеры). В `public/` — только favicon (`favicon.svg`, `favicon-48.png`, `icon-192.png`, `apple-touch-icon.png`), `og-image.jpg` (1200×630, превью для репостов), `resume.pdf`, `.nojekyll`. Не ссылайтесь на URL Figma в коде: они живут 7 дней — скачивайте файлы в `src/assets/`. Учтите: PNG-экспорты Figma часто оказываются JPEG — давайте расширение по фактическому формату (`file <имя>`).
- **Стили.** Только CSS: токены в `src/styles/tokens.css` (`--c-*`, `--fs-*`, `--r-*`, `--gutter`…), глобальные — `global.css`, остальное — `<style>` в компонентах. Tailwind не используется — при переносе кода из Figma MCP (React+Tailwind) конвертируйте в CSS и токены.
- **Адаптивность.** Макет 1728px — «эталон»; размеры шрифтов и отступов — `clamp()`. Основные брейкпоинты: `1100px` (планшет: колонка вместо сетки, бургер-меню, оглавление над статьёй) и `767px` (мобильный). Нельзя допускать горизонтального скролла на 320–1920px.
- **Анимация появления при скролле.** Атрибут `data-reveal` на элементе (и автоматически на детях `.prose`) — плавный выезд снизу, когда элемент доходит до низа экрана; логика — скрипт в `BaseLayout.astro`, стили — конец `global.css`. Задержка — `style="--reveal-delay: 0.15s"`, если у элемента своя прозрачность — `--reveal-to`. Без JS и при `prefers-reduced-motion` всё показывается сразу.
- **Доступность.** Декоративные картинки `alt=""`; осмысленные — с описанием; интерактивные элементы — настоящие `<a>`/`<button>` с `aria-label`, если нет текста; учитывайте `prefers-reduced-motion`.
- **Стиль кода.** Astro-компоненты: frontmatter с типизированным `Props`, стили в конце файла. Комментарии — по-русски, только там, где нужно объяснить «почему».

## Как добавить проект (шаблон)

Полная инструкция: [docs/ADD_PROJECT.md](docs/ADD_PROJECT.md). Коротко:

1. Положить картинки в `src/assets/projects/<slug>/` (`lead.jpg` 626×520, `preview.jpg`, `fig-N.jpg`, логотип, видео `.mp4`); крупные слайды уменьшить до ~2400 px.
2. Создать `src/content/projects/<slug>.mdx` по образцу `avito.mdx`: frontmatter (title, category, tag, description, preview, lead, leadLogo?, related?, order) + тело статьи (`## ` — разделы и оглавление, `### ` — подзаголовки, списки, `<Figure src alt />`, `<Video src label />`).
3. (Если нужен на главной) добавить карточку в `src/data/home.ts`: `{ project: '<slug>', mirrored?, cta? }` в нужную секцию.
4. Cross-ссылки: блок «Другие проекты» строится автоматически из `related` (или всех остальных проектов); хлебные крошки и «Вернуться на Главную» — в шаблоне.
5. `npm run build && npm run check:links`, посмотреть страницу на 1728 / 1024 / 390px.

## Сверка с макетом

Figma MCP: `get_design_context` (код + ассеты), `get_screenshot` (эталон), `get_metadata` (структура). Токены и размеры, снятые с макета, — в [docs/DESIGN_TOKENS.md](docs/DESIGN_TOKENS.md). Известные расхождения макетов (не «баги» реализации):
- В макетах хлебные крошки всех детальных страниц по ошибке содержат текст «Авито. Пересмотр главной страницы» — на сайте используется `shortTitle` конкретного проекта.
- Оглавление в макетах статично («Задача», «Проблемы») — на сайте строится из `##`-заголовков.
- Ширина колонки статьи в макетах 883 или 1012px — на сайте одна гибкая колонка (`1fr` + оглавление `clamp(240px, 20vw, 340px)` — уже макетных 498px по просьбе заказчика).
