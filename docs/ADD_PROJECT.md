# Как добавить новую страницу проекта

Шаблон детальной страницы один (`src/layouts/ProjectLayout.astro`). Новый проект — это один MDX-файл и картинки.

## 1. Картинки

Скачайте из Figma (Figma MCP: `get_design_context` → ссылки на ассеты; ссылки живут 7 дней) в `src/assets/projects/<slug>/`:

| Файл | Что это |
|---|---|
| `lead.jpg` | Большая картинка справа в hero — готовый кадр 626×520 (экспорт «Lead Image» из Figma; скругление 32px делает шаблон). |
| `preview.jpg` | Превью карточки на главной (16:9; на карточке обрезается до 1012×534). |
| `logo.svg` | Логотип поверх lead (необязательно). |
| `fig-1.jpg`, `fig-2.jpg`, … | Иллюстрации в теле статьи — слайды 16:9, показываются целиком, без обрезки. |
| `*.mp4` | Записи экрана для тела статьи (необязательно, см. `<Video>` ниже). |

Проверьте формат: `file lead.jpg` — экспорты Figma с расширением `.png` бывают JPEG.
Крупные слайды (5760×3240 и т. п.) перед добавлением уменьшайте до ~2400 px по ширине и сжимайте — исходники лежат в репозитории (Astro сам отдаёт webp нужных размеров). Видео — короткие, без звука, ≲ 1,5 МБ.

## 2. MDX-файл

`src/content/projects/<slug>.mdx` — `<slug>` станет частью URL: `/projects/<slug>/`.

```mdx
---
title: "Название проекта\nВторая строка заголовка"   # H1; \n = перенос строки
shortTitle: Название проекта                          # хлебные крошки и «Другие проекты» (по умолчанию title)
cardTitle: Название                                   # заголовок карточки на главной (по умолчанию shortTitle)
category: ФИНТЕХ                                      # верхняя строка карточки
tag: Мобильное приложение                             # плашка-тег на карточке
description: "Одно-два предложения для карточки и meta description."   # в кавычках, если есть «: »
preview: ../../assets/projects/<slug>/preview.jpg    # картинка карточки на главной
lead: ../../assets/projects/<slug>/lead.jpg           # кадр 626×520
leadLogo:                                             # необязательно
  src: ../../assets/projects/<slug>/logo.svg
  alt: Название бренда
  left: 5      # % от рамки lead
  top: 8
  width: 38
related: [avito, tbank]                               # необязательно; по умолчанию — все остальные проекты
order: 5                                              # порядок в списках (меньше = выше)
---

import Figure from '../../components/Figure.astro';
import Video from '../../components/Video.astro';
import fig1 from '../../assets/projects/<slug>/fig-1.jpg';
import demo from '../../assets/projects/<slug>/demo.mp4';

## Задача

Абзац текста.

<Figure src={fig1} alt="Описание иллюстрации" />

<Video src={demo} label="Запись экрана: что показано" />

## Проблемы

- Пункт списка
- Ещё пункт

### Подзаголовок внутри раздела

Текст с **жирным** выделением.
```

Правила разметки тела статьи:

- `##` — раздел; по всем `##` автоматически строится «Содержание статьи» (sticky-блок справа, на планшете/мобильном — над статьёй).
- `###` — подзаголовок 16px (как «Режим редактирования» в Kaspersky).
- Списки `-` получают фирменный маркер, абзацы/`**жирный**` стилизуются шаблоном. HTML-верстку в тексте писать не нужно.
- `<Figure src={…} alt="…" />` — картинка целиком в своих пропорциях; `fit="cover"` / `fit="contain"` — рамка 883:430 как в макете (с обрезкой / со вписыванием); `caption="…"` — подпись.
- `<Video src={…} label="…" />` — запись экрана (импортируйте `.mp4` из `src/assets`). Без звука, сама играет, пока видна на экране (при `prefers-reduced-motion` — не стартует), есть стандартные controls. `label` — описание для скринридеров.

### leadCrop — только если lead не готовый кадр

Если вместо готового кадра 626×520 в `lead` лежит большая картинка из Figma, задайте кадрирование: `leadCrop: { width: 199.96, left: -36.67, top: -30.87 }` (% от рамки; из кода `get_design_context` — класс вида `h-[135.4%] left-[-36.67%] top-[-30.87%] w-[199.96%]`). По умолчанию `{ width: 100, left: 0, top: 0 }` — картинка заполняет рамку.

`leadLogo.left/top/width` — позиция логотипа относительно рамки lead в процентах (пиксели из макета ÷ размер рамки × 100).

## 3. Карточка на главной (необязательно)

`src/data/home.ts` → нужная секция (`realized` / `managed` / `concepts` / `learning`). Карточки в секции чередуются сами (`startMirrored` у секции задаёт, с какой стороны первая); `mirrored` у карточки перекрывает это.

**Учебный проект с детальной страницей** — тексты и превью берутся из frontmatter:

```ts
{ project: '<slug>' }
```

**Проект без детальной страницы** (живой сайт, видео-презентация) — всё описывается в `home.ts`:

```ts
{
  title: 'Название',
  category: 'Фармацевтика',
  tag: 'Корпоративный сайт',
  description: '…',
  gallery: 'realized/<папка>',   // src/assets/works/realized/<папка>/
  href: 'https://example.com/',  // внешняя ссылка → откроется в новой вкладке
  ctaText: 'Перейти на сайт',    // надпись у кнопки (и в aria-label ссылки)
}
```

Картинки `src/assets/works/<раздел>/<папка>/` называйте `1-cover.jpg`, `2-home.jpg`, … — порядок по имени файла: **первая — превью карточки**, при двух и более картинках все они становятся миниатюрами-галереей (до 8 штук помещаются и на мобильном). Ссылка стоит на заголовке и кнопке (сама картинка не кликабельна). Без `href` карточка не кликабельна.

- `cta`: `'arrow'` (круглая кнопка, по умолчанию) или `'none'`. При наведении у кнопки выезжает надпись `ctaText` (по умолчанию «Перейти к кейсу»; для сайтов — «Перейти на сайт», для концептов — «Посмотреть концепт»); на планшете и мобильном (≤1100px) надпись видна всегда, кнопка стоит у правого края и открывает проект сразу; на мобильном (≤767px) миниатюры крупные (64×46px, на прежнем месте поверх превью; если не помещаются — лента листается свайпом).
- `previewPosition: '50% 30%'` — `object-position` превью, если рамка 1012×534 обрезает важное.
- Проект без карточки на главной всё равно доступен по URL и в блоке «Другие проекты».

Новая секция главной — новый объект в `homeSections` **и** пункт навигации в `src/config/site.ts` (`nav[].hash` = `id` секции).

## 4. Проверка

```bash
npm run dev            # посмотреть страницу
npm run build && npm run check:links
```

Проверьте 1728 / 1024 / 390px: заголовок, lead-картинка, оглавление, отсутствие горизонтального скролла.
