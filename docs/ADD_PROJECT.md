# Как добавить новую страницу проекта

Шаблон детальной страницы один (`src/layouts/ProjectLayout.astro`). Новый проект — это один MDX-файл и картинки.

## 1. Картинки

Скачайте из Figma (Figma MCP: `get_design_context` → ссылки на ассеты; ссылки живут 7 дней) в `src/assets/projects/<slug>/`:

| Файл | Что это |
|---|---|
| `lead.jpg` | Большая картинка справа в hero (в макете рамка 626×520, скругление 32px). Обычно 1920×1080 — кадрируется через `leadCrop`. |
| `logo.svg` | Логотип поверх lead (необязательно). |
| `fig-1.jpg`, `fig-2.jpg`, … | Иллюстрации в теле статьи (в макете рамка ~883×430). |

Проверьте формат: `file lead.jpg` — экспорты Figma с расширением `.png` бывают JPEG.
Пока настоящих картинок нет — используйте `src/assets/shared/placeholder-figure.jpg` (и добавьте пункт в `docs/TODO.md`).

## 2. MDX-файл

`src/content/projects/<slug>.mdx` — `<slug>` станет частью URL: `/projects/<slug>/`.

```mdx
---
title: "Название проекта\nВторая строка заголовка"   # H1; \n = перенос строки
shortTitle: Название проекта                          # хлебные крошки и «Другие проекты» (по умолчанию title)
cardTitle: Название                                   # заголовок карточки на главной (по умолчанию shortTitle)
category: ФИНТЕХ                                      # верхняя строка карточки
tag: Мобильное приложение                             # плашка-тег на карточке
description: "Одно-два предложения для карточки и meta description."   # в кавычках, если есть «: »
preview: ../../assets/projects/<slug>/lead.jpg        # картинка карточки на главной
thumbs: []                                            # миниатюры на карточке (список путей), необязательно
lead: ../../assets/projects/<slug>/lead.jpg
leadCrop: { width: 190, left: -80, top: -10 }         # кадрирование lead, % от рамки (см. ниже)
leadLogo:                                             # необязательно
  src: ../../assets/projects/<slug>/logo.svg
  alt: Название бренда
  left: 5      # % от рамки lead
  top: 8
  width: 38
related: [avito, tbank]                               # необязательно; по умолчанию — все остальные проекты
order: 5                                              # порядок в списках (меньше = выше)
---

import Figure from '../../components/Figure.astro';
import fig1 from '../../assets/projects/<slug>/fig-1.jpg';

## Задача

Абзац текста.

<Figure src={fig1} alt="Описание иллюстрации" />

## Проблемы

- Пункт списка
- Ещё пункт

### Подзаголовок внутри раздела

Текст с **жирным** выделением.
```

Правила разметки тела статьи:

- `##` — раздел; по всем `##` автоматически строится «Содержание статьи» (sticky-блок справа, на планшете/мобильном — над статьёй).
- `###` — подзаголовок 16px (как «Режим редактирования» в Kaspersky).
- Списки `-` получают фирменный маркер, абзацы/`**жирный**` стилизуются шаблоном. HTML-верстку в тексте писать не нужно.
- `<Figure src={…} alt="…" />`; `fit="contain"` — если картинку нельзя обрезать (по умолчанию `cover` с пропорцией 883:430 как в макете); `caption="…"` — подпись.

### leadCrop — как снять значения с Figma

В макете lead-картинка — «заливка» рамки 626×520 со смещением. Из кода `get_design_context` возьмите класс изображения вида `h-[135.4%] left-[-36.67%] top-[-30.87%] w-[199.96%]` → `leadCrop: { width: 199.96, left: -36.67, top: -30.87 }` (высота считается из пропорции 16:9). Если такого кода нет — начните с `{ width: 100, left: 0, top: 0 }` и подберите вручную.

`leadLogo.left/top/width` — позиция логотипа относительно рамки lead в процентах (пиксели из макета ÷ размер рамки × 100).

## 3. Карточка на главной (необязательно)

`src/data/home.ts` → нужная секция (`realized` / `managed` / `concepts` / `learning`):

```ts
{ project: '<slug>', mirrored: false, cta: 'arrow' }
```

- `mirrored: true` — карточка слева, превью справа.
- `cta`: `'arrow'` (круглая кнопка), `'more'` («Подробнее»), `'none'`.
- Проект без карточки на главной всё равно доступен по URL и в блоке «Другие проекты».

Новая секция главной — новый объект в `homeSections` **и** пункт навигации в `src/config/site.ts` (`nav[].hash` = `id` секции).

## 4. Проверка

```bash
npm run dev            # посмотреть страницу
npm run build && npm run check:links
```

Проверьте 1728 / 1024 / 390px: заголовок, lead-картинка, оглавление, отсутствие горизонтального скролла.
