# Дизайн-токены (из Figma)

Источник: файл Portfolio, кадры «Главная» и «Детальная_*» (ширина макета 1728px). В коде токены — `src/styles/tokens.css`.

## Цвета

| Токен | Значение | Где |
|---|---|---|
| `--c-ink` | `#100224` | основной текст, заголовки |
| `--c-text-2` | `#635a6f` | вторичный текст, описания |
| `--c-accent` | `#8a5cf6` | кнопки, акценты, ссылки |
| `--c-accent-soft` | `rgba(138,92,246,.13)` | плашка-тег |
| `--c-accent-faint` | `rgba(138,92,246,.2)` | пилюля «наверх» |
| `--c-hero-top` | `#e7defd` | верх градиента hero / низ нижнего блока |
| `--c-nav-bg` | `rgba(250,250,250,.3)` + blur 10px | капсулы навигации |
| `--c-border-nav` | `#f3f4f6` | рамка капсул |
| `--c-border-thumb` | `#e5e7eb` | рамка миниатюр |

Фоны: hero — градиент `#e7defd → #fff` сверху вниз; нижний блок главной — `#fff → #e7defd`. Поверх hero — размытая «клякса» (`src/assets/bg/blob.png`) с `mix-blend-mode: color-burn`.

## Радиусы и размеры

- Кнопки/капсулы: 60px; кнопка-круг: 72×72
- Карточка проекта: 496×534, радиус 20px; превью 1012×534, радиус 12px; зазор 20px
- Миниатюры: 78×56, радиус 6px, зазор 8px (правый нижний угол превью)
- Lead-картинка детальной: 626×520, радиус 32px
- Иллюстрация в статье: 883×430
- Оглавление: в макете 498px; на сайте уже, чтобы не сужать текст — `clamp(240px, 20vw, 340px)`, левая рамка 1px акцентного цвета, padding 20/28, sticky

## Сетка и отступы (1728px)

- Поля страницы 100px (контейнер 1528px) → `--gutter: clamp(20px, 5.8vw, 100px)`, `--container: 1528px`
- Шапка: 60px от верха, две капсулы (навигация слева, соцсети справа), padding 24/32
- Между секциями главной 200px, подпись секции → карточки 100px
- Hero главной: высота 1117px, контент прижат к низу; hero детальной: 740px, контент с 220px
- Статья: заголовок → текст 20px, между секциями 48px, элементы списка 12px

## Брейкпоинты сайта

| Ширина | Поведение |
|---|---|
| ≥ 1101px | десктоп по макету |
| ≤ 1100px | карточки в колонку (превью сверху), бургер вместо капсулы меню, оглавление над статьёй, hero детальной в колонку |
| ≤ 767px | мобильный: кнопки на всю ширину, уменьшенные отступы/капсулы |
